04 / FAQ

Sawaal, jawab.

FailureAI kya karta hai?

Ek AI digital marketing agent hai jo ek brand naam ya URL se client research, ad copy, creative prompts, tracking code, prompt library, 30-day calendar aur SEO pack banata hai — Hindi, Hinglish aur English me.

API key zaruri hai kya?

Nahi. Built-in Local Engine bina kisi key ke poora structured kit deta hai. Zyada nuance chahiye to Settings me OpenAI / Gemini / Anthropic key daalein (ya server .env me) — Live AI mode automatically on ho jata hai.

Kya main isse live deploy / host kar sakta hoon?

Haan. npm start se local, Dockerfile se kisi bhi VPS, ya render.yaml se Render / Railway par. SEO ke liye dynamic sitemap.xml, robots.txt, canonical tags, Open Graph aur 4 JSON-LD blocks pehle se hain. Domain set karne ke liye PUBLIC_SITE_URL env var daalein.

Client ki "real" data kaise aati hai?

Settings me "Live web research" on karein aur server par Tavily / Serper / Brave key set karein. Tab sources Client Intel me cite hote hain. Bina key ke bhi structured lead sheet, data gaps aur enrichment checklist milti hai — hum kabhi bhi facts invent nahi karte.

Images sach me generate hoti hain?

Haan: Creative Studio har concept ke saath detailed image prompt deta hai aur "Render image" free public image endpoint se actual image banata hai. Apni IMAGE_API_KEY set karne par server-side image generation bhi milta hai. Prompts Midjourney, SDXL, DALL·E aur Ideogram me seedha paste kar sakte hain.

Data kahan save hota hai?

Aapke browser me (localStorage) — workspaces, history aur settings. Server stateless hai aur koi analytics / tracking nahi bhejta. Public deploy par API keys server .env me rakhein, browser me nahi.
